# Documentation dependency audit exception

The documentation site has a **temporary, conditional release-risk exception**
for its production dependency audit. It is not a claim that the site has no
known dependency vulnerabilities.

The Docusaurus MDX toolchain currently resolves `image-size@2.0.2`. GitHub
lists two high-severity denial-of-service advisories for that version:

- [GHSA-w3rx-r6r6-pgpr](https://github.com/advisories/GHSA-w3rx-r6r6-pgpr)
- [GHSA-5p2g-fcmc-qvqq](https://github.com/advisories/GHSA-5p2g-fcmc-qvqq)

Neither advisory currently has a patched package version. The exception is
tracked in [issue #36](https://github.com/0x63616c/agent-runtime/issues/36)
and expires at **2026-11-08T00:00:00Z** unless explicitly renewed through a
new decision.

## What remains enforced

Every documentation check still runs `npm audit --omit=dev`. The gate accepts
only this exact locked package version and these exact two high advisories. It
fails for a new high or critical finding, dependency drift, expiration, or an
audit that becomes clean while this exception has not been removed. Typecheck,
production build, generated-documentation freshness, and all non-audit checks
remain mandatory.

This exception is limited to the static documentation build. It does not cover
the Go runtime, public API, examples, or any other dependency graph. See
[ADR-0013](https://github.com/0x63616c/agent-runtime/blob/main/docs/adr/0013-temporary-documentation-audit-exception.md)
for the binding policy and removal criteria.
