The Go foundation gate and the documentation site are currently runnable. Use
the repository's `just check` gate for Go foundation changes. Use `just docs`
to install the locked documentation dependencies and start the local site.

The local infrastructure Stack is runnable on OrbStack. Read the
<DocLink href="/docs/build-and-run/local-stack">isolated local Stack guide</DocLink> for its precise command,
security, and product-boundary guarantees.
