Agent Runtime is being built as one Go monorepo for durable, session-based
agents. Its intended boundary includes versioned Agents, Sessions, Turns,
streamed Events, approvals, artifacts, governed tools, provider adapters,
Temporal orchestration, and optional sandboxes.

:::caution[Current boundary]
The repository ships a public HTTP API and Go SDK, local example applications,
and an isolated local Stack. The supplied standalone API uses explicitly
labelled in-memory storage for exploration. Verified Firecracker isolation and
production deployment remain separate operator-owned capabilities. See the
<DocLink href="/docs/reference/runtime-go-contract">runtime Go contract</DocLink> and
<DocLink href="/docs/build-and-run/local-stack">local Stack guide</DocLink> for the
exact boundaries.
:::

Start with <DocLink href="/docs/concepts/runtime-language">the domain language</DocLink>, then read
<DocLink href="/docs/security/verified-boundaries">the verified safety boundary</DocLink>, and then
work through the <DocLink href="/docs/tutorials/durable-chat">Durable Chat tutorial</DocLink>.
