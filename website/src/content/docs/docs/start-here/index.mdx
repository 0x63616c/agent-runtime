# Agent Runtime

Agent Runtime is being built as one Go monorepo for durable, session-based
agents. Its intended boundary includes versioned Agents, Sessions, Turns,
streamed Events, approvals, artifacts, governed tools, provider adapters,
Temporal orchestration, and optional sandboxes.

:::caution[Implementation status]
M0 and the M2 reusable Temporal payload-library milestone are complete.
Declarative infrastructure and the sandbox control contract are under
implementation. The repository now ships a runnable isolated Tilt
infrastructure Stack with trust-scoped API/orchestration/codec runtime roles,
and the first Temporal-free public Go contract plus deterministic Agent kernel.
It does not yet ship the HTTP transport, PostgreSQL runtime authority, private
Temporal orchestration, three examples, production payload deployment, or
verified Firecracker isolation. See the [runtime Go contract](../reference/runtime-go-contract.mdx)
and [local Stack guide](../build-and-run/local-stack.mdx) for the exact current
boundaries.
:::
