# Examples

The sandbox contract has a small compile-tested Go construction example. It
shows the explicit `OperationRequest` shape and finite `ResourceLimits`; it
does not start a sandbox because no public control transport or backend is
composed yet.

Durable Chat now has a loopback web UI and terminal UI at
[`examples/durable-chat`](https://github.com/0x63616c/agent-runtime/tree/main/examples/durable-chat).
It uses only the public Go SDK/HTTP contract to create/resume Sessions, queue
input, reconnect events by cursor, inspect state, and cancel Turns. Its web
server owns the local SDK bearer so the browser never receives it.

The example is not a Codex subscription canary. The official production
subscription Model surface remains blocked, so no example may label its model
path subscription-verified until the protected live canary is retained.

Workspace Agent currently has a public-SDK approval inbox slice: it lists,
inspects, approves, denies, and cancels the Turn behind an owner-scoped
Approval without exposing action arguments, capability material, or sandbox
descriptors. Its Workspace sandbox execution remains unavailable until the
protected Firecracker profile has Linux/KVM evidence; this is not a runnable
Workspace Agent completion claim.

Research Dossier is not yet implemented. The complete three-example local Tilt
E2E suite is also not complete, so this page does not claim a clean local
demonstration yet.
