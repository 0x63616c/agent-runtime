# Examples

The sandbox contract has a small compile-tested Go construction example. It
shows the explicit `OperationRequest` shape and finite `ResourceLimits`; it
does not start a sandbox because no public control transport or backend is
composed yet.

Durable Chat, Workspace Agent, and Research Dossier are required public-contract
applications, but none is implemented in M0. This page will link executable
tutorials only when the examples consume the real public HTTP contract and Go
SDK and pass their clean local Tilt demonstrations.
