# Reference status

The completed M0 foundation publishes the deterministic
[source inventory](./generated/source-inventory.mdx), and current M3 work adds a
compile-tested Go declaration for the `sandbox` control contract. The
contract declares principal-scoped idempotent Operations, immutable Effective
Specs, typed process results, bounded output replay, finite limits, and safe
image-admission metadata.

This is not yet a public HTTP/OpenAPI service, durable database implementation,
or sandbox host backend. `NewClient` validates explicit client configuration
but reports unavailable until a control transport is composed. The deterministic
in-memory fixture is unit/conformance evidence only; it does not claim process
restart durability, Firecracker enforcement, or tenant isolation.

The completed M2 milestone provides the implementation-tested public
[Temporal payload reference](./temporal-payloads.mdx). Its local converter
compares complete wire representations before keeping normal, zstd, or
immutable blob-reference payloads. The Temporal UI handler reuses that chain
only for inspection; workers retain no remote-codec dependency. This is a
library slice, not yet a deployed runtime role or production blob deployment.

The active M5 work now provides a Temporal-free public
[Go contract and deterministic kernel](./runtime-go-contract.mdx). It defines
typed IDs, immutable revision/session snapshots, idempotent bounded Input,
serialized Turn state, explicit cancellation, and ordered cursor replay. The
HTTP/OpenAPI transport is implemented, while the runtime role still uses its
explicitly labelled in-memory test store. The declared
[Go SDK symbol index](./generated/go-sdk-symbols.mdx) is generated from the
documented public `sdk/go` declarations and methods; it records source shape,
not additional runtime evidence. The declared
[PostgreSQL data-authority foundation](./postgresql-data-authority.mdx) now has
reviewed bounded schema artifacts, a disposable PostgreSQL constraint proof,
and a narrow internal first-admission repository seam. That seam is not wired
to public routes, records an outbox without a publisher or recovery guarantee,
and does not imply durable cursors or the Temporal adapter.

Generated files live only under `website/src/content/docs/docs/reference/generated/`. Curated
pages explain semantics and ownership without duplicating unverified schemas.
