The local `cmd/firecracker-e2e` capability report currently refuses execution on
Darwin because it is not Linux, has no `/dev/kvm` or cgroups v2, and has no
reviewed final fixture lock or enrolled protected host configuration. The
current `just firecracker-smoke` and `just firecracker-integration` aliases
write only a fail-closed preflight report; they do not launch a VM. Do not
replace this block with a simulated pass.
